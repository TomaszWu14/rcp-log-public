# Archiwum: pierwsza wersja dokumentacji analitycznej

Dokumenty 01–07 w tym katalogu to pierwsza wersja opisu prototypu (problem, proces, user flow,
model danych, 38 wymagań, decyzje, ograniczenia). Zastąpiła je dokumentacja przedwdrożeniowa
w katalogu nadrzędnym (`docs/00-przeglad.md` i dalsze), która porządkuje tę samą wiedzę w procesy
P1–P7 z regułami BR-n i wymaganiami WF-n. Identyfikatory wymagań z pliku `05-wymagania.md`
(REJ-01, SES-02, …) są nadal nazwami testów w `tests/test_wymagania.py`; mapę na WF-n zawiera
każdy dokument procesu.
