# Słownik pojęć

Słownik pojęć domenowych (pobyt, wpis, strefa, podstrefa, nadwyżka, korekta, alert, grafik…) jest
w [02-dane/model-danych](../02-dane/model-danych.md). Nazwy w kodzie są polskie (`strefa`, `pracownik`)
i takie zostają — to język domeny, nie dług.

Pojęcia procesu zespołu (spoza domeny):

| Pojęcie | Znaczenie |
|---|---|
| WF-n, BR-n, T-n, B-n, D-n, Z-n | wymaganie, reguła, dług techniczny, problem bezpieczeństwa, decyzja, ustalenie — numeracja z `docs/00–05` |
| NFR-nnn | wymaganie niefunkcjonalne ([WYMAGANIA](WYMAGANIA.md)) |
| US-nnn | historyjka zmiany w backlogu ([HISTORYJKI](HISTORYJKI.md)) |
| R-n | ryzyko w rejestrze ([RYZYKA](../bezpieczenstwo/RYZYKA.md)) |
| ADR nnnn | decyzja architektoniczna; D1–D11 liczą się jako 0001–0011 |
